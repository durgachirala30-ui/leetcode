# Search Insert Position — LeetCode 35

## Problem Statement

Given a sorted array of distinct integers and a target value, return the index if the target is found.

If the target is not found, return the index where it would be inserted in order.

The algorithm must have **O(log n)** time complexity.

### Example

**Input:**

```text
nums = [1,3,5,6]
target = 5
```

**Output:**

```text
2
```

### Another Example

**Input:**

```text
nums = [1,3,5,6]
target = 2
```

**Output:**

```text
1
```

---

## Approach

We use **Binary Search** because the array is sorted.

1. Set `left = 0` and `right = len(nums) - 1`.
2. Find the middle element:

   ```python
   mid = (left + right) // 2
   ```
3. If `nums[mid] == target`, return `mid`.
4. If `nums[mid] < target`, the target must be on the right side, so move `left` to `mid + 1`.
5. If `nums[mid] > target`, the target must be on the left side, so move `right` to `mid - 1`.
6. When the loop ends, `left` represents the correct position where the target should be inserted.
7. Return `left`.

---

## Code

```python
class Solution:
    def searchInsert(self, nums, target):
        left = 0
        right = len(nums) - 1

        while left <= right:
            mid = (left + right) // 2

            if nums[mid] == target:
                return mid

            elif nums[mid] < target:
                left = mid + 1

            else:
                right = mid - 1

        return left
```

---

## Time Complexity

**O(log n)**

Binary search reduces the search space by approximately half in every iteration.

## Space Complexity

**O(1)**

Only a few variables such as `left`, `right`, and `mid` are used.
